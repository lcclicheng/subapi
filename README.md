# 桌面坦克大战

一个使用 Python 标准库 Tkinter 编写的桌面端坦克大战小游戏，不需要额外安装第三方依赖。

## 运行方式

```bash
python3 main.py
```

如果你的系统只有 `python` 命令，也可以运行：

```bash
python main.py
```

## 操作说明

- `方向键` 或 `W/A/S/D`：移动坦克
- `空格` 或 `J`：发射炮弹
- `R`：游戏结束后重新开始

## 游戏目标

- 玩家有 3 条生命。
- 击毁敌方坦克可得 1 分。
- 达到 10 分即可获胜。
- 炮弹可以摧毁砖墙，注意利用掩体躲避敌方攻击。
