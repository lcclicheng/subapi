# 桌面坦克大战

一个使用 Python 标准库 Tkinter 编写的桌面端坦克大战小游戏，不需要额外安装第三方依赖。画面风格参考经典 8-bit 坦克大战：黑色战场、灰色边框、红砖、钢墙、树林、水域、基地、像素风坦克和程序窗口图标。

## 运行方式

```bash
python3 main.py
```

如果你的系统只有 `python` 命令，也可以运行：

```bash
python main.py
```

## 操作说明

- `Enter`：在标题界面开始游戏；结束后也可以再来一局
- `方向键` 或 `W/A/S/D`：移动坦克
- `空格` 或 `J`：发射炮弹
- `P`：暂停 / 继续
- `Esc`：返回标题界面
- `R`：游戏结束后重新开始

## 游戏目标

- 玩家有 3 条生命。
- 保护底部基地，基地被敌方炮弹击中会失败。
- 击毁敌方坦克可得分，不同敌人分值不同。
- 达到 18 分即可获胜。
- 胜负界面会显示最终分数、击毁数、生存时间和最高分。
- 炮弹可以摧毁红砖，钢墙和水域会阻挡坦克与普通炮弹。
- 树林可以遮挡坦克和炮弹，适合伏击或躲避。

## 技能道具

击毁敌人后有概率掉落技能方块，玩家碰到即可自动触发：

- `S` 护盾：短时间抵挡敌方炮弹。
- `R` 速射：提高开火速度，并让炮弹可以击穿钢墙。
- `F` 冰冻：短时间冻结所有敌人。
- `B` 炸弹：立即清除当前场上的敌人。
- `L` 生命：回复 1 条生命，最多 5 条。

## 配置和记录

游戏会在本地生成 `tank_battle_config.json`，用于保存最高分、难度、窗口尺寸和音效开关。这个文件是本地游玩记录，不会提交到仓库。

## 打包成桌面程序

如果要发给 Windows 用户，可以安装 PyInstaller 后打包成单文件桌面程序：

```bash
python -m pip install pyinstaller
pyinstaller --onefile --windowed --name TankBattle main.py
```

打包完成后，程序会出现在 `dist/` 目录中。后续如果准备 `.ico` 图标文件，可以在命令中追加：

```bash
pyinstaller --onefile --windowed --name TankBattle --icon path/to/icon.ico main.py
```
